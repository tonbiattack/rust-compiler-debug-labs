# 題材メモ：ローカル参照の返却で発生する E0515

| 項目 | 決定 |
| --- | --- |
| 契約 | 入力の前後をトリムし、小文字化したラベルを返す。 |
| Red | 関数内の`String`への`&str`を返そうとしてE0515になる。 |
| 直接原因 | ローカル変数は関数終了時に破棄され、返却参照の借用元になれない。 |
| 最小修正 | `String`を所有値として返す。 |
| 回帰 | トリム・小文字化と、内部空白を保つことを統合テストする。 |

既存のE0597とE0716は借用中にスコープまたは文末で値が破棄される事例です。本題材はAPIがローカル値への参照を関数外へ返そうとする境界を扱い、所有値を返す設計判断に焦点を置きます。
