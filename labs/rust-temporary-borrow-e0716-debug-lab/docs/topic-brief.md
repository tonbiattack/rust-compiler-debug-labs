# 題材メモ：一時値の借用で発生する E0716

| 項目 | 決定 |
| --- | --- |
| 対象 | Rust 1.75.0、関数呼び出しで生成した一時的な `String` の借用 |
| 契約 | 生成した `"fast,safe"` の最初の区切り要素の文字数として `4` を返す。 |
| Red | `&make_line()` の参照を変数へ保存して次の文で使い、`cargo check` が E0716 で終了コード101になる。 |
| 直接原因 | 一時値は通常、生成された文の終わりに破棄されるが、参照は次の文まで使われる。 |
| 最小修正 | 生成した `String` を明示的なローカル変数へ束縛してから借用する。 |
| 最終観測 | 関数の戻り値が最初の区切り要素の文字数 `4` であることを統合テストで確認する。 |

既存記事にある E0597 は内側スコープのローカル変数が先に破棄される事例です。本題材は、関数呼び出しで作られる一時値の文末での破棄と、`let`束縛による生存期間の延長を扱うため、発火条件と修正の中心が異なります。
