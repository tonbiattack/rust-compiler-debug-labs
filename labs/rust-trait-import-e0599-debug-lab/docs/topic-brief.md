# 題材メモ：トレイト未導入で発生するE0599

| 項目 | 決定 |
| --- | --- |
| 契約 | メモリバッファへ`ready`を書き込み、文字列として返す。 |
| Red | `Cursor`へ`write_all`を呼ぶが、`Write`トレイトを導入しない。 |
| 直接原因 | メソッドは`Write`トレイトで提供され、トレイトがスコープにない。 |
| 最小修正 | `use std::io::{Cursor, Write};` としてトレイトを導入する。 |
| 回帰 | 書き込み結果が`ready`であることを統合テストする。 |

既存題材の型不一致とは異なり、本題材は型が必要なトレイトを実装していても、メソッド解決に必要なトレイト名がスコープにない条件を扱います。
