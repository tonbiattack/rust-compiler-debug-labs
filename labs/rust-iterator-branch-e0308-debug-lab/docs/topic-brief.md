# 題材メモ：分岐ごとのイテレータ具象型で発生する E0308

| 項目 | 決定 |
| --- | --- |
| 契約 | `include_closed` に応じて `open` のみ、または `open` と `closed` を列挙する。 |
| Red | `if` の一方が配列イテレータ、他方が `Once` を返し、E0308になる。 |
| 直接原因 | `impl Iterator` の戻り値は一つの具体型である必要があり、分岐の具象型が異なる。 |
| 最小修正 | 両分岐を `Box<dyn Iterator<Item = &'static str>>` にそろえる。 |
| 回帰 | 閉じた状態を含む場合と含まない場合を統合テストする。 |

既存題材はイテレータの消費や`zip`の長さ契約を扱います。本題材は`impl Iterator`の不透明な戻り型と分岐の具体型不一致を扱うため、原因と修正が異なります。
