# トレイト必須項目不足で発生する E0046 を読むデバッグラボ

タスクラベルを整形し、カテゴリを返す。 を題材に、E0046を最小修正で解く教材です。

## この題材で守る契約

> タスクラベルを整形し、カテゴリを返す。

## 最短の開始手順

```bash
cargo test
```

## バグを再現する

バグ状態のコミット`dddc8eb`で`cargo check`を実行するとE0046を再現できます。
