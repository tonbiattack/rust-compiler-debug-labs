# 題材メモ：借用中の移動で発生するE0505

| 項目 | 決定 |
| --- | --- |
| 契約 | ラベルの先頭語と完全なラベルを連結する。 |
| Red | `label`の一部を借用した後に、`label`を所有値として移動する。 |
| 直接原因 | 借用`prefix`が後で使われるため、借用元を移動できない。 |
| 最小修正 | `label`を移動せず、書式化時も共有借用で使う。 |
| 回帰 | `daily: daily-report`を返すことを統合テストする。 |

既存題材のE0507は共有参照越しのフィールド移動です。本題材は同じローカル値を部分借用したまま、そのローカル値自体を移動する時点の借用範囲を扱います。
