# 私有メソッド呼び出しで発生する E0624 を読むデバッグラボ

タスク題名を表示用に取得する。 を題材にE0624を最小修正で解く教材です。

## この題材で守る契約

> タスク題名を表示用に取得する。

## 最短の開始手順

```bash
cargo test
```

## バグを再現する

バグ状態のコミット`d0b41c0`で`cargo check`を実行するとE0624を再現できます。
