# 不変な再代入で発生する E0384 を読むデバッグラボ

待機時間を10秒へ上限設定する。 を題材にE0384を最小修正で解く教材です。

## この題材で守る契約

> 待機時間を10秒へ上限設定する。

## 最短の開始手順

```bash
cargo test
```

## バグを再現する

バグ状態のコミット`b34d30d`で`cargo check`を実行するとE0384を再現できます。

## 観測の要約

| バグ状態 | 修正後 |
|---|---|
| E0384でコンパイル失敗 | `mut`で再代入可能にする。 |
