# 題材メモ：複数入力参照とE0106

| 項目 | 決定 |
| --- | --- |
| 契約 | 主ラベルが空でなければ主ラベル、空なら既定ラベルを返す。 |
| Red | 複数の`&str`入力から`&str`を返す署名で寿命を省略し、E0106を出す。 |
| 直接原因 | 返り値がどの入力から借用されるかを省略規則で一意に決められない。 |
| 最小修正 | 二つの入力と返り値に同じ明示的ライフタイムを付ける。 |
| 回帰 | 主ラベルと既定ラベルを返す二条件を統合テストする。 |

既存題材のE0515は関数ローカルへの参照返却です。本題材は呼び出し元が所有する複数入力のうち、どの寿命を返り値が共有するかを関数署名で表す問題です。
