# 複数入力参照で発生する E0106 を読むデバッグラボ

複数の`&str`から`&str`を返す関数で、返り値の借用元を省略して発生する E0106 を学ぶ最小教材です。

## この題材で守る契約

> 主ラベルが空でなければ主ラベルを、空なら既定ラベルを返します。

## 最短の開始手順

```bash
cargo test
```

修正後は統合テスト2件が成功します。

## バグを再現する

バグ状態のコミット `2c29836` で `cargo check` を実行します。

```bash
git switch --detach 2c29836
cargo check
git switch main
```

`missing lifetime specifier` を含む E0106 が表示されます。

## 観測の要約

| 観測点 | バグ状態 | 修正後 |
| --- | --- | --- |
| 返り値の借用元 | 省略規則で決められない | 二入力と返り値で同じ寿命を明示 |
| コンパイル | E0106で失敗 | `cargo check` が成功 |
| 契約 | 実行前に停止 | 二つの選択条件を満たす |

## スコープ

このラボは二つの入力が同じ寿命を共有する最小例だけを扱います。異なる寿命から参照を選ぶ設計や構造体のライフタイムは対象外です。
