# 非公開フィールドアクセスで発生する E0616 を読むデバッグラボ

タスクの題名を公開APIから取得する。 を題材に、E0616を最小修正で解く教材です。

## この題材で守る契約

> タスクの題名を公開APIから取得する。

## 最短の開始手順

```bash
cargo test
```

## バグを再現する

バグ状態のコミット`c6858c7`で`cargo check`を実行するとE0616を再現できます。

## 観測の要約

| バグ状態 | 修正後 |
| --- | --- |
| E0616でコンパイル失敗 | 読み取り専用getterを追加する。 |
