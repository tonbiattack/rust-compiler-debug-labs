# 題材メモ：`split_at_mut` が解く E0499

| 項目 | 決定 |
| --- | --- |
| 対象 | Rust 1.75.0、同一スライスからの可変参照の取得 |
| 契約 | 先頭2要素を `10` と `20` に更新し、残りの要素を保持する。 |
| Red | `values[0]` と `values[1]` への可変借用を同時に作り、`cargo check` が E0499 で終了コード101になる。 |
| 直接原因 | コンパイラは添字式だけから二つの可変参照が非重複であることを一般に証明できない。 |
| 最小修正 | `split_at_mut(1)` で非重複な二つの部分スライスを得る。 |
| 最終観測 | 3要素の残存値と、要素数が2の境界ケースを統合テストで確認する。 |

既存記事にある E0502 は同一 `String` の不変借用と可変借用の競合です。本題材は、添字アクセスによる二つの可変借用と、標準ライブラリの `split_at_mut` が表す非重複保証を扱うため、修正方法と学習対象が異なります。
