# 題材メモ：共有参照からのフィールド移動で発生する E0507

| 項目 | 決定 |
| --- | --- |
| 契約 | 共有参照の`Job`から、所有するラベルの複製を返して元のラベルを保持する。 |
| Red | `&Job` の `String` フィールドをそのまま返そうとしてE0507になる。 |
| 直接原因 | 共有参照は所有権を渡さず、`String` は `Copy` ではない。 |
| 最小修正 | `job.label.clone()` で独立した所有値を作る。 |
| 回帰 | 戻り値と、呼び出し後も元のフィールドが使えることを確認する。 |

既存のE0382は変数間の所有権移動後の再利用です。本題材は共有参照越しの構造体フィールドから所有値を移動できない契約を扱うため、発火位置とAPI設計の判断が異なります。
